How to file a claim

These details make a proof claim easier for other people to pick up, whether it appears on a forum, in an arXiv comment, or here.

  1. State the theorem exactly, with its definitions named.
  2. Give the document a fixed identity: link and SHA-256 of the PDF.
  3. List the papers, results, and prior claims you build on, with versions.
  4. Say what you did not check, and which tools you used and for what.
  5. Name the parts you consider risky.
