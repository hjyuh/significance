# Explanation rewrite tasks

`check_category: deslopping` labels tasks as **De-slopping / explanation rewrite**.
Tasks remain grouped by claim on the task index, with a dedicated rewrite section
linking to the workflow in [George Coote’s repository](https://github.com/GeorgeCoote/openai_372_deslop).
This reference does not imply an affiliation or an accepted submission.

Use `task_kind: exposition`. Name the source version, the bounded passage, the
deliverable and unresolved ambiguities. Distinguish AI-assisted readable drafts
from human-written rewrites; follow the destination repository’s authorship
requirements. An explanation is not a mathematical assessment and must not be
counted as one. Completed work can be recorded using existing exposition evidence.
