# Successor path

Significance is intentionally starting as a portable layer, not a competing
problem website. The useful test is whether a reader can follow a problem-page
link to a record and find work that another reader can continue.

## Shipped now

- A validated YAML record with source/version identity and attributed claims.
- A reader-first review map: where to start, delicate steps, prerequisites,
  and one-click open tasks.
- Named reviewer pages, append-only evidence/history, and a neutral backlog.
- A generated `/problems/` index linking the two Rafik Zeraoulia records to
  ErdősProblems.com #653 and #726. This is a real interoperability seam, not a
  promise of complete coverage.
- Formal-artifact receipts where a pinned Lean build can be reproduced, with
  the trust profile and correspondence limits shown explicitly.

## The next adoption loop

1. A venue or author links one record from the original problem page.
2. A reader takes one bounded task and adds an attributed note or receipt.
3. The record's timeline preserves what was checked, by whom, and against
   which version.
4. The format is exported or consumed by another tracker, so the work does not
   disappear when a site changes its presentation.

This is the bridge between Tao's workflow (generation, verification, clear
communication, community digestion, canonicalization) and the backlog problem:
each stage is represented as typed, version-bound evidence rather than as a
single truth badge.

## Deliberately not promised

The index is not a full Erdős problem database, a peer-review venue, a truth
oracle, a ranking system, or a paid marketplace. Coverage should grow only when
there is an attributed record someone is willing to stand behind.
